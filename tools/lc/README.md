# 전과정평가 페이지 '두 갈래 공급망' 장면 렌더 소스

`public/lc/map-*.webp`, `public/lc/mask_*.png`, `components/lc/map.json`은 이 코드로 직접 만든 등각 장면입니다. 외부 모델 · AI 이미지 없음.
03 재활용 공정 지도(`../rc/plant.py`)의 파쇄기 · 침출조, 01 재제조 작업장(`../rm/workshop.py`)의 전기차,
09 이력관리(`../tr/passport.py`)의 점선 도우미, 10 재생원료 인증(`../ce/certify.py`)의 재질 · 묶음 도우미와 조명 · 카메라를 그대로 씁니다.

```bash
pip install bpy pillow            # bpy 5.1에서 확인
python render.py w=2800 s=48 out=out      # 장면 + 단계 마스크 6장 + 좌표 (CPU 2코어 약 15분)
python export.py out ../../public/lc ../../components/lc/map.json
```

장면 구성(장면 파일 `footprint.py`): 같은 양극재 1 kg을 두 길로 만듭니다.
- 뒤 길(남색 점선, 광산에서 오는 원료): ① 노천 광산(계단식 언덕 · 굴착기 · 광석 더미 · 트럭) → ② 제련 · 정제(굴뚝 둘 · 탱크) → ③ 배로 먼 운송(물 · 부두 · 화물선).
- 앞 길(청록 점선, 폐배터리에서 오는 원료): ④ 수거(전기차 · 수거 상자 · 팩을 실은 트럭) → ⑤ 재활용 공장(03의 파쇄 · 선별 + 침출조) ← ⑥ 발전 단지(석탄 굴뚝 · 냉각탑 · 석탄 더미 · 태양광 판 · 변압기, 호박색 점선 = 전력선).
- 두 길은 오른쪽 양극재 공장에서 만나고, 공장 지붕 위에 큰 유리 기둥 두 개(왼쪽 광산 길 합계 · 오른쪽 재활용 길 합계)가 있습니다.
- 단계마다 옆에 빈 유리 '탄소 기둥'이 있습니다. **기둥 높이는 개념이며 실제 수치가 아닙니다**(실제 수치는 페이지 그림 3).
배치는 설명용으로 단순화했고 실제 공급망과 다릅니다.

## 공정 재생 (LED 흐름선 + 기둥 채우기)

01~10 지도와 같은 공통 도구(`../rc/motion_kit.py` · `../rc/motion_export.py`)를 씁니다. 모든 동작이 덧그림이라 클린 배경은 없습니다.

```bash
python animate.py out=out/anim only=dry                       # 렌더 없이 자세 · 움직이는 범위 점검
python animate.py out=out/anim                                # 흐름선 좌표 · 가림 마스크 · 동작 프레임 (CPU 2코어 약 25분)
python ../rc/motion_export.py out/anim out/lca.png ../../public/lc/map ../../components/lc/motion.json
```

- 흐름선: 뒤 길(①②③ → 공장) → 앞 길(④⑤ → 공장) → 전력선(발전 단지 → ⑥ 재활용 공장 배전함).
- ① 굴착기 등 · 바가지 광석, ② 굴뚝 연기, ③ 배 뒤 물살 · 굴뚝 연기, ④ 트럭 짐칸 단자 등, ⑤ 침출조 용액 · 배전함 빛,
  ⑥ 석탄 굴뚝 연기 동안 기둥이 높이 찼다가 태양광 판이 켜지면 낮아짐(높았던 자리에 고리 표시).
- 같은 순간 양극재 공장 지붕 위 큰 기둥에 그 단계 몫이 한 칸씩 쌓입니다(클립 `c_*`, 끝난 칸은 남음). ⑥은 재활용 길 기둥 옆에 '전력에 따라 이 사이' 괄호(위 끝 = 지금 높이, 아래 끝 = 그 1/5)를 그립니다.
