# 메인 '네 층위' 패널 3D 그림

`public/home/layer-<층위>.webp`(1400×1800) · `layer-<층위>-700.webp`(700×900) · `layer-<층위>-m.webp`(폰 780×440, 투명 배경)은 이 코드로 만듭니다.
Blender(bpy)를 파이썬 코드로 움직여 직접 만든 장면입니다. 외부 모델 · AI 이미지 없음. 재질 · 조명 · 카메라는 03 재활용 지도(`../rc/plant.py`)와 같습니다.

```bash
pip install bpy pillow                       # bpy 5.1에서 확인
python render.py w=1000 s=96 out=out          # 네 장면을 투명 배경으로 (CPU 2코어 약 7분)
python compose.py out ../../public/home       # 층위색 그러데이션 위에 얹어 데스크톱 · 폰용 그림
```

| 층위 | 장면 (`panels.py`) |
|---|---|
| 처리 경로 | 받침대 위 다 쓴 팩에서 네 갈래 길이 섬 넷으로 — ① 재제조(바꿔 끼우는 모듈) ② 재사용(ESS 캐비닛) ③ 재활용(깔때기 + 결정) ④ 업사이클링(플라스크 + 분말, 길만 점선) |
| 지원 기술 | 앞에서 뒤로 높아지는 3단 진열대 — 05 진단기 · 06 방화함, 07 로봇 팔 · 08 전해액 통, 09 QR 태그 · 10 인증 도장 |
| 평가 | 계단처럼 올라가는 막대 셋 — 11 탄소 구름 · 12 동전 더미 · 13 화물선 섬, 위로 이어지는 선 끝에 노란 구슬 |
| 설계 | 도면 위에서 위로 분해된 팩 — 트레이 → 큰 셀 여섯 → 버스바 · 띠 → 클립 → 뚜껑, 모서리 점선 안내선 |

- 자리 배분(`compose.py`): 데스크톱 그림은 패널 폭이 바뀌어도(평소 약 0.4, 펼치면 약 0.8 비율) 가운데를 기준으로 잘려 보이므로
  물체를 가운데 폭 36% · 높이 13~58% 안에 둡니다. 위쪽은 메뉴 바, 아래 40%는 제목 · 설명 · 주제 버튼 자리입니다.
  설계 칸은 오른쪽 위치 표시 점(LAYERS)을 피해 조금 왼쪽으로 둡니다.
- 폰(900px 이하)에서는 그림이 패널 맨 위 띠가 되고 글은 그 아래 층위색 바탕에 놓입니다(`app/globals.css`). 폰 그림은 투명 배경이라 바탕과 이음매가 없습니다.
- 처리 경로 장면의 떠 있는 섬은 바닥 그림자를 끕니다(어두운 구멍처럼 보여서). 세로로 긴 장면이라 카메라 `sensor_fit`을 가로 기준으로 둡니다.
- 층위색은 `components/Art.tsx`의 `layerGrad`, `app/globals.css`의 `.panel[data-layer]`와 같은 값입니다.
