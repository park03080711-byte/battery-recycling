# 공급망 · 자원안보 페이지 '섬을 도는 원료' 장면 렌더 소스

`public/sc/map-*.webp`, `public/sc/mask_*.png`, `components/sc/map.json`은 이 코드로 직접 만든 등각 장면입니다. 외부 모델 · AI 이미지 없음.
03 재활용 공정 지도(`../rc/plant.py`)의 파쇄기, 01 재제조 작업장(`../rm/workshop.py`)의 전기차,
10 재생원료 인증(`../ce/certify.py`)의 묶음 도우미, 11 전과정평가(`../lc/footprint.py`)의 트럭 · 재질과 조명 · 카메라를 그대로 씁니다.

```bash
pip install bpy pillow            # bpy 5.1에서 확인
python render.py w=2800 s=48 out=out      # 장면 + 단계 마스크 6장 + 좌표 (CPU 2코어 약 15분)
python export.py out ../../public/sc ../../components/sc/map.json
```

장면 구성(장면 파일 `islands.py`): 바다 위 섬 넷.
- 뒤 왼쪽 ① 광산 섬: 계단식 노천 광산 · 굴착기 · 광석 더미 · 트럭, 리튬 염수 증발지 넷, 정제 섬으로 건너는 광석 바지선.
- 뒤 오른쪽 ② 정제 섬: 굴뚝 달린 정제 공장 넷이 한곳에 몰려 있음. 앞 왼쪽 작은 섬에 다른 나라 정제 공장 하나.
- ③ 화물선: 정제 섬 부두에서 한국 섬 부두로 바다를 건넘(경고 부표 = 물류 위험).
- 앞쪽 한국 섬: ④ 배터리 공장(양극재 소성로 · 셀 공장) → 청록 점선 고리 → ⑤ 수거(전기차 · 수거 상자 · 팩 트럭) → ⑥ 재활용(03 파쇄기 + 전처리 용량 통) → ④.
- **정제 섬의 공장 수는 쏠림을 보여 주는 개념**입니다. 재활용 통 앞면 눈금(호박색 선)은 2030년 국내 사용후 배터리가 국내 전처리 용량의 11%를 채운다는 추정(김유정 2024)의 자리입니다.
섬의 배치는 설명용으로 단순화했고 실제 지리와 다릅니다.

## 공정 재생 (LED 흐름선 + 설비 동작)

01~12 지도와 같은 공통 도구(`../rc/motion_kit.py` · `../rc/motion_export.py`)를 씁니다. 모든 동작이 덧그림이라 클린 배경은 없습니다.

```bash
python animate.py out=out/anim only=dry                       # 렌더 없이 자세 · 움직이는 범위 점검
python animate.py out=out/anim                                # 흐름선 좌표 · 가림 마스크 · 동작 프레임 (CPU 2코어 약 25분)
python ../rc/motion_export.py out/anim out/sc.png ../../public/sc/map ../../components/sc/motion.json
```

- 흐름선 둘: 광산 섬 → 바지선 → 정제 섬 → 화물선 → 한국 섬 공장, 그다음 한국 섬 고리(공장 → 수거 → 재활용 → 공장).
- ① 굴착기 등 · 바가지 광석 · 염수 증발지가 차례로 반짝 · 바지선 물살, ② 몰린 섬 굴뚝 여덟에서 연기가 오르고 늦게 작은 섬 굴뚝 둘(클립 `m2o`, 같은 단계),
  ③ 화물선 뒤 물살 · 연기 · 부표 깜빡임, ④ 공장 창 · 소성로 빛, ⑤ 트럭 짐칸 팩 단자 등 · 수거 상자 경고 띠, ⑥ 컨베이어 알갱이 · 통 눈금이 0에서 11%까지 참.
- 가림 마스크는 바다 · 섬 땅 · 점선을 빼고 만듭니다(`occ(skip=("plat", "lane", "sea", "isl"))`).
