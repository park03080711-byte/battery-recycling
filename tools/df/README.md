# 분해를 고려한 설계 페이지 '두 팩 나란히 뜯기' 장면 렌더 소스

`public/df/map-*.webp`, `public/df/mask_*.png`, `components/df/map.json`은 이 코드로 직접 만든 등각 장면입니다. 외부 모델 · AI 이미지 없음.
03 재활용 공정 지도(`../rc/plant.py`)의 파쇄기 · 재질과 11 전과정평가(`../lc/`)의 조명 · 카메라를 그대로 씁니다.

```bash
pip install bpy pillow            # bpy 5.1에서 확인
python render.py w=2800 s=48 out=out      # 장면 + 단계 마스크 6장 + 좌표 (CPU 2코어 약 15분)
python export.py out ../../public/df ../../components/df/map.json
```

장면 구성(장면 파일 `packs.py`): 같은 크기의 팩 두 개를 작업대 위에 나란히 놓았습니다.
- 왼쪽 뜯기 어려운 팩: ① 볼트 서른여섯 · 실링 띠로 닫힌 뚜껑 → ② 모듈 열둘(나사 넷씩) · 배선 묶음 둘 → ③ 셀을 굳힌 접착제 줄 · 용접 점 → 앞쪽 파쇄기와 블랙매스 더미.
- 오른쪽 뜯기 쉬운 팩: ④ 클립 여섯으로 닫힌 뚜껑 → ⑤ 모듈 없이 큰 셀 여덟을 누르는 띠 둘 · 한쪽 끝 버스바 묶음 → ⑥ 앞면 식별 무늬 · 앞쪽 셀 선반.
- 팩마다 옆에 '걸린 시간' 막대 기둥이 있습니다.
- **두 팩 모두 개념 도식**입니다. 볼트 · 나사 · 셀 수는 설명용이며, 페이지의 숫자는 실제 팩 여섯을 따진 연구(Lander 외 2023)에서 가져왔습니다.

## 공정 재생 (LED 흐름선 + 설비 동작)

01~13 지도와 같은 공통 도구(`../rc/motion_kit.py` · `../rc/motion_export.py`)를 씁니다. 모든 동작이 덧그림이라 클린 배경은 없습니다.

```bash
python animate.py out=out/anim only=dry                       # 렌더 없이 자세 · 움직이는 범위 점검
python animate.py out=out/anim                                # 흐름선 좌표 · 가림 마스크 · 동작 프레임 (CPU 2코어 약 25분)
python ../rc/motion_export.py out/anim out/df.png ../../public/df/map ../../components/df/motion.json
```

- 흐름선 둘: 어려운 팩 한 바퀴(뚜껑 → 모듈 → 셀 → 파쇄기), 그다음 쉬운 팩 한 바퀴(뚜껑 → 띠 · 버스바 → 셀 → 선반).
- ① 볼트가 하나씩 빛나며 풀리고, ② 나사 마흔여덟이 둘씩 풀린 뒤 배선이 빛나고, ③ 접착제 줄이 붉게 · 용접 점에 불꽃 · 조각이 파쇄기로 떨어짐,
  ④ 클립 여섯이 빠르게, ⑤ 걸쇠 넷 · 버스바 묶음이 빛나고, ⑥ 식별 무늬를 읽은 뒤 셀이 하나씩 표시되며 선반에 그대로 놓임.
- 단계마다 그 팩의 막대에 한 칸씩 쌓입니다(클립 `c_<단계>`, 같은 단계, 끝난 칸은 남음). **높이는 개념**으로, 어려운 팩 합이 쉬운 팩의 약 4배입니다(셀까지 뜯는 비용 194 대 47달러를 본뜸).
