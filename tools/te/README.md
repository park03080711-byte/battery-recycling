# 기술경제성 분석 페이지 '돈이 오가는 공장' 장면 렌더 소스

`public/te/map-*.webp`, `public/te/mask_*.png`, `components/te/map.json`은 이 코드로 직접 만든 등각 장면입니다. 외부 모델 · AI 이미지 없음.
03 재활용 공정 지도(`../rc/plant.py`)의 파쇄기 · 침출조, 01 재제조 작업장(`../rm/workshop.py`)의 팩 · 모듈,
09 이력관리(`../tr/passport.py`)의 점선 도우미, 10 재생원료 인증(`../ce/certify.py`)의 드럼 · 안전모,
11 전과정평가(`../lc/footprint.py`)의 트럭 · 재질과 조명 · 카메라를 그대로 씁니다.

```bash
pip install bpy pillow            # bpy 5.1에서 확인
python render.py w=2800 s=48 out=out      # 장면 + 단계 마스크 6장 + 좌표 (CPU 2코어 약 15분)
python export.py out ../../public/te ../../components/te/map.json
```

장면 구성(장면 파일 `money.py`): 다 쓴 팩이 공장을 한 바퀴 돕니다.
- 뒤 줄(남색 점선을 따라 오른쪽으로): ① 운송(먼 길 · 거리 표지 · 팩을 실은 트럭) → ② 해체(작업대 위 열린 팩 · 떼어 낸 모듈 · 안전모 · 기둥 시계) → ③ 파쇄 · 블랙매스(03의 파쇄 · 선별).
- 꺾어서 앞 줄(왼쪽으로): ④ 정제(03의 침출조 · 약품 드럼 · 배전함) → ⑤ 판매(니켈 · 코발트 · 리튬 · 망간 상자) → ⑥ 큰 저울(왼쪽 산호색 접시 = 비용, 오른쪽 청록 접시 = 수익).
- 단계마다 옆에 빈 '동전 쟁반'이 있습니다(띠 색: 산호 = 비용, 청록 = 수익).
- **동전 수와 저울의 기울기는 개념이며 실제 수치가 아닙니다**(실제 수치는 페이지 그림 2~4).
배치는 설명용으로 단순화했고 실제 공장과 다릅니다.

## 공정 재생 (LED 흐름선 + 동전 · 저울)

01~11 지도와 같은 공통 도구(`../rc/motion_kit.py` · `../rc/motion_export.py`)를 씁니다.

```bash
python animate.py out=out/anim only=dry                       # 렌더 없이 자세 · 움직이는 범위 점검
python animate.py out=out/anim                                # 흐름선 좌표 · 클린 배경 · 가림 마스크 · 동작 프레임 (CPU 2코어 약 30분)
python ../rc/motion_export.py out/anim out/te.png ../../public/te/map ../../components/te/motion.json
```

- 흐름선: 길 → ① 트럭 → 뒤 줄 ②③ → 꺾어서 앞 줄 ④⑤ → ⑥ 저울.
- ① 트럭 앞등 · 거리 표지가 차례로 켜짐, ② 시계 바늘이 돌고 모듈이 차례로 잠깐씩 표시됨, ③ 컨베이어 알갱이가 흐름,
  ④ 침출조 용액 · 약품 드럼 등 · 배전함 계기, ⑤ 금속 상자 뚜껑이 차례로 빛남.
- 같은 순간 그 단계 쟁반에 동전이 쌓입니다(비용 2 · 2 · 4 · 5개, 수익 14개).
- ⑥ 저울 보 · 접시는 원래 장면에서 지운 클린 배경(`plate_bal`) 위에 클립으로 그립니다. 비용 동전 13개가 왼쪽 접시에 모이며 보가 비용 쪽으로 기울고,
  수익 동전 14개가 오른쪽 접시에 모이면 반대로 넘어가 수익 쪽으로 살짝 기운 채 멈춥니다(국내 분석의 B/C 1.06을 떠올리게 한 개념 연출).
- ② 시계 바늘과 ⑥ 저울 보는 클립에만 있으므로 제자리 모습(`-rest-`)을 함께 내보냅니다.
