# 재생원료 인증 페이지 '인증서가 나오는 공장' 장면 렌더 소스

`public/ce/map-*.webp`, `public/ce/mask_*.png`, `components/ce/map.json`은 이 코드로 직접 만든 등각 장면입니다. 외부 모델 · AI 이미지 없음.
03 재활용 공정 지도(`../rc/plant.py`)의 파쇄기 · 침출조, 01 재제조 작업장(`../rm/workshop.py`)의 팩 · 모듈,
09 이력관리(`../tr/passport.py`)의 기록 기둥 · 점선 · 식별 무늬 도우미와 재질 · 조명 · 카메라를 그대로 씁니다.

```bash
pip install bpy pillow            # bpy 5.1에서 확인
python render.py w=2800 s=48 out=out      # 장면 + 단계 마스크 6장 + 좌표 (CPU 2코어 약 15분)
python export.py out ../../public/ce ../../components/ce/map.json
```

장면 구성(장면 파일 `certify.py`): 원료가 지나는 길(청록) 위에 ① 입고 · 계량(폐배터리 팩 · 공정 스크랩 통, 바닥 저울)
→ ② 파쇄 · 선별(파쇄기 · 자력 선별 · 블랙매스 톤백 저울) → ③ 정제(침출조 → 재생원료 8종 통, 제품 저울)
→ ④ 인증 심사(서류 더미 · 안전모 둘 = 현장 심사원 · 둥근 심의 탁자 · 인증서 액자) → 갈림점
→ ⑤ 소재 · 셀 공장(함유율 표시판) / ⑥ 수출(컨테이너 · 식별 무늬가 붙은 모듈).
단계마다 '기록 기둥'이 있고, 파란 점선(데이터 선)이 가운데 뒤 '투입 · 산출 기록판'으로 모입니다.
분홍 점선은 사후관리(분기마다 서류 · 수시 현장) 길로, ④에서 판 앞 가장자리를 따라 ① 입구로 돌아갑니다.
통 뚜껑 색은 원료 종류(탄산리튬 · 수산화리튬 · 황산니켈 · 황산코발트 · 황산망간 · 흑연 · 복합금속침전물 · 양극활물질)를 구분하는 표시일 뿐입니다.
식별 무늬는 QR 모양을 흉내 낸 무작위 무늬이며 실제 코드가 아닙니다. 배치는 설명용으로 단순화했고 실제 공장 · 제도 운영과 다릅니다.

## 공정 재생 (LED 흐름선 + 기록 동작)

01~09 지도와 같은 공통 도구(`../rc/motion_kit.py` · `../rc/motion_export.py`)를 씁니다. 모든 동작이 덧그림이라 클린 배경은 없습니다.

```bash
python animate.py out=out/anim only=dry                       # 렌더 없이 자세 · 움직이는 범위 점검
python animate.py out=out/anim                                # 흐름선 좌표 · 가림 마스크 · 동작 프레임 (CPU 2코어 약 25분)
python ../rc/motion_export.py out/anim out/cert.png ../../public/ce/map ../../components/ce/motion.json
```

- 흐름선: 입구 → ①②③④ → 갈림점 → ⑤ 소재 · 셀 / ⑥ 수출, 마지막으로 ④에서 분홍 길을 따라 ① 입구(사후관리).
- ①~③: 저울 테두리가 깜빡이며 무게를 재고 표시기가 켜집니다(① 큰 저울 → 스크랩 저울, ② 컨베이어 알갱이 → 톤백 저울, ③ 통 뚜껑 8개 → 제품 저울).
- ④: 서류 더미 세 개(서류 심사) → 안전모 둘(현장 심사) → 둥근 탁자(심의) → 인증서 종이와 도장이 빛납니다.
- ⑤: 벽 표시판의 함유율 막대가 판의 일부만큼 차고 셀 머리가 빛남. ⑥: 식별 무늬와 컨테이너 문이 빛남.
- 같은 순간 기록 기둥을 타고 빛 고리가 올라가고, 가운데 뒤 기록판의 그 단계 줄(클립 `r_*`)에 막대가 그려집니다. 끝난 줄은 남습니다.
  ①~③ 줄은 남은 양(단계 색) + 줄어든 양(주황), ④는 도장 + 짧은 막대, ⑤⑥은 전체(회색) 가운데 재생원료 몫. **막대 길이는 개념이며 실제 수치가 아닙니다.**
